# Cost model: Buy vs Hybrid vs Build (3-year)
Script: `analysis/cost_model.py`. Every input is an editable assumption, and every number below is regenerated by running it.

## Pricing facts (checked 2026-10-17)
| Item | Price | Source |
|---|---|---|
| Power Apps Premium | $20/user/mo ($12 with 2,000+ seats); unlimited apps per user | [MS pricing](https://www.microsoft.com/en-us/power-platform/products/power-apps/pricing) |
| Power Apps per-app | $5/user/app/mo | [MS licensing FAQ](https://learn.microsoft.com/en-us/power-platform/admin/powerapps-flow-licensing-faq) |
| Power Apps pay-as-you-go | Billed per monthly active user per app via Azure | [PAYG meters](https://learn.microsoft.com/en-us/power-platform/admin/pay-as-you-go-meters) |
| Power Apps code apps | Every end user still needs Premium / PAYG / App Pass | [code apps](https://learn.microsoft.com/en-us/power-apps/developer/code-apps/overview) |
| Devin Teams | $40 per full seat per month (Pro-level quota) + shared on-demand credits; up to 200 users | [Devin self-serve](https://docs.devin.ai/admin/billing/self-serve) |
| Devin Enterprise | ACU-based, quote only. Adds SAML/OIDC SSO, admin controls, dedicated deployment option | [devin.ai/pricing](https://devin.ai/pricing) |
| Senior US fintech engineer, fully loaded | ~$200–265K/yr (published range; we use $230K, ≈ $5K per eng-week) | trio.dev, stealthagents 2026 |

**Implication:** $250K ÷ $240 per user per year ≈ **1,040 Premium users**. Because Premium covers unlimited apps, **the 10 new apps cost ~$0 in extra licence on Buy**, unless they bring new users. That cuts against a "save the licence" pitch built around app count.

## The three options
- **Buy:** keep Power Apps; engineers build the 10 new apps in canvas/model-driven.
- **Hybrid:** keep Power Apps; Devin builds the new apps as Power Apps *code apps* (React on Power Platform).
- **Build:** in-house platform built with Devin; Power Apps runs until renewal after migration, then is dropped.

## Key assumptions (base case)
| | Buy | Hybrid | Build |
|---|---|---|---|
| Licence | $250K, +15%/yr (ops growth) | same | Paid in Y1 only (contract runs to renewal) |
| Power Platform admin/ALM | 0.25 FTE | 0.25 FTE | 0.25 FTE in Y1 only |
| Devin | none | $30K/yr placeholder | $30K/yr placeholder |
| Eng-weeks per new app | 2.0 | 1.25 | 1.25 |
| One-off | none | none | Platform 8 wk + migrating 3 apps 4.5 wk |
| Ongoing extras | none | none | 0.5 FTE platform owner, $15K hosting, $20K pen test |
| App upkeep | 0.5 wk/app/yr | same | same |

## Results (thousands of USD)
| Scenario | Buy 3yr | Hybrid 3yr | Build 3yr | Build Y1 / Y3 vs Buy Y1 / Y3 |
|---|---|---|---|---|
| **Base** | 1,203 | 1,256 | **1,035** | 595 / 212 vs 375 / 421 |
| Licence flat (no user growth) | 1,085 | 1,138 | **1,035** | |
| Licence optimised to $150K (light users moved to per-app/PAYG) | **856** | 908 | 935 | |
| Build goes badly (1 FTE owner, 3 wk/app, 16 wk platform) | **1,203** | 1,256 | 1,508 | |
| Devin at $100K/yr (Enterprise guess) | 1,203 | 1,466 | 1,245 | |
| Devin at $10K/yr (a few Teams seats) | 1,203 | 1,196 | **975** | |

**Break-even:** Build beats Buy over 3 years only if the licence is above **~$185K/yr with user growth** or **~$225K/yr flat**. After migration, Build runs at **~$210–230K/yr vs ~$400K+ for Buy**, so it pays back the Y1 overlap in roughly 1–1.5 years. The longer the horizon, the better Build looks.

## What this says
1. **Hybrid is not a cost option.** It's the most expensive or tied in every scenario, because you pay the licence *and* for Devin and engineering. It only earns a place if Microsoft-run governance is a **hard compliance requirement**, or as a short **transition state**. As a destination, "have both" doesn't make financial sense.
2. **So there are really two choices: Buy or Build.** Buy's real alternative isn't Hybrid. It's **Buy + optimise the licence**, which on these numbers beats Build over 3 years.
3. **Build wins on cost only if three things hold:**
   - The licence really scales with ~1,000 users.
   - The platform stays at ≤0.5 FTE to own.
   - Per-app effort stays low.

   If any one fails, Build loses. The cost case is **modest and conditional**. Build's stronger arguments are control, testability, one SDLC, and avoiding per-user pricing as ops grows.
4. **Year 1 is always more expensive to Build (~+$220K)**, because the licence and the build overlap.
5. **Devin's price is small next to the licence and FTE lines**, unless Enterprise pricing is high. Get a quote before the pitch is final.

## Inputs to validate with the VP (they flip the result)

3. Who would own the platform, and whether 0.5 FTE is realistic.
4. Current engineering time spent on Power Apps (admin, building, fixing).
5. Whether security/compliance needs Devin Enterprise (SSO, dedicated deployment).
